# AI Answering Machine

تطبيق Android مستقل لمجيب مكالمات ذكي، مبني بـ Kotlin وJetpack Compose وMaterial 3. هذا المستودع في **PHASE 1**: أساس معماري قابل للتوسع، بدون ادعاء تنفيذ ميزات التحكم بالمكالمات أو الذكاء الاصطناعي قبل التحقق من دعم الجهاز وواجهات Android الرسمية.

## الحالة الحالية

- مشروع Android أحادي الوحدة باسم `app`.
- Kotlin + Jetpack Compose + Material 3.
- MVVM/Clean Architecture package boundaries.
- Hilt مُجهز للحقن.
- Navigation Compose مُجهز بثلاث وجهات أولية.
- أساس DataStore وRoom وWorkManager مضاف كاعتمادات للمرحلة التالية.
- واجهة Dashboard أولية تدعم RTL عبر `supportsRtl` ومصادر النصوص.
- Room/DataStore مربوطان بـ Hilt مع سجل مكالمات وقواعد متصلين.
- طبقة `CallScreeningService` رسمية pass-through؛ لا تحظر أو ترد تلقائيًا في هذه المرحلة.
- اختبارات وحدات أولية للـ domain/mappers.
- وضع تجربة محلي لإضافة مكالمات وقواعد تجريبية وفحص Inbox بدون Telecom أو إنترنت.

## تجربة النسخة الأولية

بعد تشغيل التطبيق:

1. استخدم **تشغيل / إيقاف المجيب** لاختبار إعداد DataStore.
2. استخدم **إضافة مكالمة تجريبية** ثم افتح **المكالمات الذكية**.
3. افتح **قواعد المتصلين** ثم اضغط **إضافة قواعد تجريبية**.
4. اضغط على قاعدة لحذفها.

للتجربة الواضحة افتح **مركز التجربة** من Dashboard، اختر سيناريو، ثم اضغط **تشغيل محاكاة المكالمة**. ستظهر الحالات والنتيجة مباشرة، وسيُحفظ الملخص أيضًا في **المكالمات الذكية**.

مركز التجربة لا يشغّل الصوت بمجرد فتح الشاشة؛ الصوت يبدأ بعد الضغط على **تشغيل محاكاة المكالمة**. يحتاج الهاتف إلى محرك Text-to-Speech مفعل وصوت وسائط مرفوع.

## اختبار مكالمة حقيقية

بعد تثبيت نسخة تحتوي على تكامل الهاتف:

1. افتح التطبيق واضغط **تعيين كتطبيق الهاتف الافتراضي**.
2. وافق على دور الهاتف الافتراضي من Android.
3. اختياريًا فعّل **Call Screening** أيضًا.
4. اتصل من هاتف آخر.
5. ستظهر المكالمة في التطبيق مع أزرار الرد والرفض والإنهاء.

هذا التكامل يختبر التحكم الحقيقي بالمكالمة فقط. لم يتم الادعاء بعد بإمكانية إدخال صوت TTS في المسار الخلوي.

من **الإعدادات** يمكن تفعيل **الرد التلقائي** واختيار تأخير 5 أو 10 أو 15 أو 30 ثانية. يعمل هذا فقط عندما يكون التطبيق Default Phone App، ويجيب المكالمة دون أن يضمن تشغيل صوت AI للطرف الآخر.

هذه البيانات محلية ومقصودة للاختبار فقط، وليست أحداث مكالمات حقيقية.

## المتطلبات

- Android Studio حديث يدعم AGP 8.7.3.
- JDK 17.
- Android SDK Platform 35 وBuild Tools مناسبة.

الإعدادات الحالية: `minSdk = 26`، `targetSdk = 35`، `compileSdk = 35`. تم اختيار API 26 كحد أدنى لأن الطبقة الأساسية تستهدف أجهزة حديثة، مع إبقاء تكاملات Telecom الرسمية مشروطة بقدرات إصدار Android ودور التطبيق لاحقًا.

## البناء

من Android Studio: افتح مجلد المشروع ثم نفّذ Sync وBuild.

لخطوات الرفع اليدوي إلى GitHub، راجع [GITHUB_UPLOAD.md](GITHUB_UPLOAD.md).

من الطرفية بعد توفير Gradle wrapper أو Gradle محلي:

```text
gradle assembleDebug
gradle test
```

لم تكن Java/Gradle/Android SDK متاحة في بيئة إنشاء هذا الهيكل، لذلك لم أضع ادعاء نجاح build أو tests.
